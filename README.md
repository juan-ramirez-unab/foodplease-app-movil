# FoodPlease – App móvil (Flutter)

FoodPlease es una aplicación móvil desarrollada en Flutter que permite
visualizar menús de locales gastronómicos y navegar entre productos.

## Tecnologías
- Flutter
- Dart
- Material Design

## Requisitos
- Flutter SDK instalado
- Android Studio o VS Code

## Ejecución
1. Clonar el repositorio
2. Ejecutar `flutter pub get`
3. Ejecutar `flutter run`

## Estructura del proyecto
- lib/ → código principal de la aplicación
- assets/ → recursos gráficos
- mockups/ → prototipos baja y alta fidelidad

## Estado del proyecto
Proyecto en fase MVP. Utiliza datos mockeados y no cuenta con backend.




## Instalación y ejecución de la aplicación

1. Clonar el repositorio:

   git clone https://github.com/juan-ramirez-unab/foodplease-app-movil


2. Ingresar al directorio del proyecto:

cd foodplease-app-movil


3.Instalar las dependencias del proyecto:


flutter pub get

4. Verificar dispositivos disponibles:


flutter devices


5. Ejecutar la aplicación:


flutter run
